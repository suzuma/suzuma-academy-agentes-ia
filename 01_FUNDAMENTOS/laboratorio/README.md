# Laboratorio 01 — Diseña un agente antes de programarlo

## Objetivo
Convertir un problema cotidiano en una especificación básica de agente.

## Entregable
Completa:

- problema;
- usuario;
- objetivo;
- entradas;
- acciones;
- herramientas;
- condición de finalización;
- riesgos;
- intervención humana.

## Reto
Dibuja el flujo:

`usuario → agente → acción → observación → decisión → resultado`

# Estructura del repositorio

Las carpetas numeradas siguen la progresión pedagógica del curso.

`presentacion/` contiene las presentaciones de clase.

`MATERIAL_DOCENTE/` contiene apoyos para quien imparte el curso.

`MATERIAL_ALUMNO/` contiene el libro y materiales destinados al estudiante.

`ASSETS/` queda reservado para recursos visuales publicables.

La fotografía maestra de SuZuMa Cyber Instructor y los archivos internos de identidad visual deben conservarse fuera de un repositorio público.

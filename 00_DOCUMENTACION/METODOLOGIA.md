# Metodología

El curso avanza de conceptos fundamentales hacia sistemas de agentes cada vez más completos.

La progresión propuesta es:

**concepto → ejemplo → práctica → laboratorio → integración**

Cada módulo busca que el estudiante pueda explicar el concepto, implementarlo y reconocer sus límites.

El proyecto integrador funciona como hilo conductor para aplicar:

- Prompt Engineering
- Python
- memoria y estado
- herramientas
- RAG
- planificación
- arquitecturas multiagente
- evaluación
- observabilidad
- despliegue
- seguridad

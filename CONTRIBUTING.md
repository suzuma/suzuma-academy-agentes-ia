# Contribuir

Las mejoras al material deben conservar la estructura pedagógica del curso.

Antes de publicar cambios:

1. Verificar que no existan claves, tokens o datos personales.
2. Revisar ortografía y consistencia de terminología.
3. Mantener la numeración de módulos.
4. Actualizar `CHANGELOG.md` cuando el cambio sea relevante.
5. Evitar incorporar archivos de referencia internos o privados.

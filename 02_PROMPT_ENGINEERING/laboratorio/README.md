# Laboratorio 02 — Diseña y prueba un prompt

## Objetivo
Crear una primera versión de prompt y evaluarla con casos de prueba.

## Plantilla

```text
CONTEXTO:
OBJETIVO:
ENTRADA:
REGLAS:
FORMATO:
CRITERIOS DE CALIDAD:
SI FALTA INFORMACIÓN:
```

## Entregable
Crear al menos 5 casos de prueba y registrar:

- entrada;
- respuesta;
- fallo observado;
- modificación realizada;
- nueva respuesta.

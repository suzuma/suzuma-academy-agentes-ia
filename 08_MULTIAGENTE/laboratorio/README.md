# Laboratorio 08 — Arquitectura Multiagente

## Objetivo

Separar una tarea en especialistas y utilizar un coordinador para combinar sus resultados.

## Ejecutar

```bash
python equipo_agentes.py
```

## Agentes

- Investigador
- Analista
- Redactor
- Coordinador

## Reto

Agrega un especialista y define el contrato de entrada y salida.

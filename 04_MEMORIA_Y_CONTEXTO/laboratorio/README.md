# Laboratorio 04 — Memoria y Contexto

## Objetivo

Agregar memoria conversacional a un agente.

La memoria del laboratorio es deliberadamente sencilla: una lista de mensajes en memoria del proceso.

## Ejecutar

```bash
python agente_memoria.py
```

## Reto

Amplía el agente para:

- limitar el número de mensajes recordados;
- distinguir mensajes del usuario y del agente;
- mostrar un resumen del contexto actual.

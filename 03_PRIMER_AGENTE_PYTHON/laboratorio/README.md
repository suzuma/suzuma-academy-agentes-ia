# Laboratorio 03 — Primer agente con Python

## Objetivo

Construir un agente educativo mínimo y comprender su ciclo básico:

```text
usuario → agente → respuesta → usuario
```

La primera versión utiliza un modelo simulado para que el laboratorio pueda ejecutarse sin API keys.

## Ejecutar

```bash
python agente_basico.py
```

## Reto

Modifica el agente para que:

1. Detecte una intención sencilla.
2. Mantenga el nombre del usuario.
3. Responda de forma diferente según la intención.

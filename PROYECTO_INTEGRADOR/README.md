# Proyecto Integrador — Construye tu propio agente de IA

El proyecto integra los aprendizajes del curso en una solución funcional.

## Componentes

- Problema y usuario
- Historias de usuario
- Arquitectura
- Herramientas
- RAG
- Memoria y estado
- Planificación
- Multiagente, cuando sea pertinente
- Seguridad
- Evaluación
- Observabilidad
- Versionado
- README y documentación
- Demo

La presentación del proyecto y el manual del docente contienen la guía de trabajo y criterios de evaluación.

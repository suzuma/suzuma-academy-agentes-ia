# Licencia y derechos de uso

Esta versión del repositorio se publica inicialmente **sin otorgar una licencia abierta adicional**.

Los materiales del curso, presentaciones, libros, documentación y recursos gráficos permanecen reservados a sus respectivos titulares de derechos, salvo que un archivo indique expresamente otra licencia.

Si posteriormente se desea permitir reutilización, adaptación o distribución, puede incorporarse una licencia específica para:

- materiales educativos;
- código fuente;
- recursos gráficos.

No se deben asumir permisos de reutilización únicamente por encontrarse un archivo publicado en GitHub.

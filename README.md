## 🎯 ¿Qué es este curso?

**Creación de agentes de IA, de lo básico a lo intermedio** es una ruta formativa diseñada para que el estudiante avance desde los conceptos fundamentales de inteligencia artificial hasta la construcción, evaluación y despliegue de agentes capaces de utilizar herramientas, consultar documentos, mantener contexto y coordinar tareas.

La propuesta combina:

**conceptos → ejemplos → práctica → laboratorio → integración**

El objetivo no es solamente utilizar un asistente de IA, sino comprender **cómo se diseña y construye un sistema basado en agentes**.

## 🔌 Conexión con modelos reales

Se agregó `00_DOCUMENTACION/llm/` con un adaptador configurable mediante:

```text
LLM_API_URL
LLM_API_KEY
LLM_MODEL
```

Las credenciales permanecen fuera del repositorio. El adaptador es deliberadamente neutral para que el curso pueda explicar primero la arquitectura y después adaptar el cliente al proveedor elegido.

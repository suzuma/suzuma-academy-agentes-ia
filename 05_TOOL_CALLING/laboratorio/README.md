# Laboratorio 05 — Tool Calling

## Objetivo

Comprender la idea de una herramienta como una función que el agente puede invocar.

Este laboratorio utiliza herramientas locales para evitar dependencias externas.

## Ejecutar

```bash
python agente_tools.py
```

## Herramientas incluidas

- `hora_actual`
- `sumar`
- `buscar_concepto`

## Reto

Agrega una herramienta nueva y define:

- nombre;
- descripción;
- parámetros;
- validación;
- resultado.
